## v0.6.1

### The matching got better, so you'll see more issues 📈
Nearly everything in this release makes the analyzer notice spellings it used
to walk straight past. Your issue count will go up compared to your last
export — possibly by a lot. Nothing has broken: those variations were always
in your library, the tool just couldn't see them.

Almost all of this came from people posting real examples in Issues and
Discussions. Please keep them coming — nearly every item below started as
somebody's screenshot.

### New
- **Accented spellings now group** — *Motörhead* meets *Motorhead*, *Déjà
  Voodoo* meets *Deja Voodoo*. Accents are ignored when matching; the
  original spelling is always what gets displayed, and which one is "right"
  is still your call.
- **Look-alike accents get a chip** — when two spellings differ only by which
  accent they carry, a blue chip shows the exact character and its Unicode
  codepoint. Romanian and Turkish spellings in particular can differ by a
  mark that is effectively invisible at normal text size. Obvious differences
  like *Motörhead* don't get a chip — you can already see those.
- **Featured artists** — *(feat. …)*, *[ft. …]* and *(featuring …)* are now
  ignored when matching, so those sit alongside the plain title.
- **Punctuation and spacing** — *Albert Hammond, Jr.* meets *Albert Hammond
  Jr*, and *T. Rex* meets *T.Rex*.
- **& and "and"** — now handled the same way on tracks and albums as it
  always was on artists. *9th & Hennepin* meets *9th and Hennepin*.
- **More apostrophe styles** — acute accents, backticks and modifier
  apostrophes join the curly quotes. These are scattered through older tags
  and split songs across separate Last.fm pages.
- **Square brackets and parentheses** — *Ramalama [Bang Bang]* meets
  *Ramalama (Bang Bang)*.

### Fixed
- **Remasters dated in the title** — *Close to Me - 2006 Remaster* now groups
  with *Close to Me*. This is the standard Spotify format and it was matching
  nothing at all. 
- **Numerically titled tracks** — tracks named with just a number were being
  lumped together, so Crystal Castles' *1991* and *1983* showed up as
  variations of each other. They don't any more.
- **Android uploads** — the file picker should now let you select a CSV. I
  couldn't reproduce the original report on my own Pixel, so if you were
  affected I'd be grateful to know whether this actually helps.

### Changed
- The "smart quote" warning now names the character it found (e.g. `` ` ``
  U+0060) rather than the category. More useful when you're searching Last.fm
  for the offending scrobble, and it won't go stale as more characters get
  added.

### For contributors
- `tests/merge-contract.js` — a dependency-free Node script pinning which
  names should and shouldn't be treated as the same thing. Run
  `node tests/merge-contract.js` before changing any matching rule. It found
  two of the bugs fixed above.

Thanks to @Maeldun for a steady stream of real examples and an export to test
against, @cs188creations for the featured-artist cases, and @DavidVI18 for the
Android report.
